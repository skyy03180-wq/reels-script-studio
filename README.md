# 릴스 대본 스튜디오

뷰티 릴스 나레이션 대본(+선택 시 인스타 캡션)을 만드는 단일 HTML 웹앱입니다.

## 사용
https://skyy03180-wq.github.io/reels-script-studio/ 를 열고, 상단에 Google AI Studio에서 발급한
Gemini API 키를 한 번만 입력하면 이 브라우저에 저장됩니다. 키는 브라우저(localStorage)에만
저장되고 서버로 보내지 않습니다.

## 구성
- 제품 소구점 이미지·PDF 여러 개 업로드(합쳐 8개까지, 섞어서 가능)
- 제품 소구점 텍스트
- 레퍼런스 영상 업로드(18MB 이하는 인라인, 초과 시 Files API 업로드)
- 레퍼런스 영상 링크 입력(공개 YouTube는 fileData로 직접 분석, 인스타 등 나머지 링크는 프롬프트 참고용 + 인스타 안내 문구)
- 소구점 PDF(19MB 인라인 예산 안이면 inlineData, 초과 시 Files API 업로드 후 ACTIVE 확인)
- 모델: API 키로 쓸 수 있는 모델을 `/v1beta/models`에서 자동으로 받아 목록을 채우고, 고른 모델이 없어졌으면(404) 쓸 수 있는 모델로 바꿔 자동으로 한 번 더 시도
- 캡션 작성 ON/OFF, 길이(20초/30초), 밈 강도, 후킹 스타일
- 나레이션 대본 / 캡션 원클릭 복사

`index.html` 단일 파일로 동작하며 빌드 과정이 없습니다.

## 릴스 자동 편집기 (`/editor/`)
https://skyy03180-wq.github.io/reels-script-studio/editor/

대본 스튜디오에서 뽑은 나레이션 대본과 휴대폰 클립으로 9:16 릴스를 브라우저에서 바로 만드는 편집기입니다.

- 클립 여러 개 업로드(mp4·mov·webm) → 끌어서 순서 변경, 클립별 시작/끝 구간, 배속 1.0~1.5x, 9:16 자동 센터 크롭
- 대본 붙여넣기 → `[0~3초 / 후킹]` 같은 타임코드·지문을 지우고 문장별 자막 블록으로 나눠 전체 길이에 자동 배분
- 자막 블록별 시간·문구·색(노랑/흰색/핑크) 수정, 하단 안전영역(인스타 UI) 위에 배치
- 나레이션 파형 분석으로 무음 구간 자동 컷(임계값 dB·최소 무음 조절), BGM 추가와 볼륨 밸런스
- 오프닝 타이틀 2줄(블랙한산스/주아/노토), 굵은 외곽선과 색 프리셋
- 1080×1920 실시간 캔버스 미리보기, 재생/일시정지/스크럽
- 내보내기: WebCodecs(H.264+AAC) + mp4-muxer ESM으로 MP4, MediaRecorder 실시간 녹화 폴백, 캡컷용 SRT

`editor/index.html` 단일 파일(빌드 없음)이며, 영상·오디오는 브라우저 안에서만 처리됩니다.
