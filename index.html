사용 팁+
  • 레퍼런스는 인스타 릴스를 화면 기록하거나 저장한 파일을 그대로 올리면 돼요. 3~60초면 충분해요.
  • 영상 파일 대신 링크만 넣어도 돼요. 공개된 YouTube 링크는 영상으로 바로 분석하고, 인스타그램처럼 바로 읽지 못하는 링크는 참고 자료로만 전달돼요.
  • 작은 영상은 바로 분석하고, 큰 영상은 Gemini에 자동 업로드한 뒤 분석해요(진행률 표시). 1분 이내 영상이면 충분해요.
  • 영상이 없어도 이미지·PDF·텍스트만으로 대본을 만들 수 있어요. 영상이 있으면 컷 템포와 말투까지 맞춰요.
  • 제품 가이드라인·브랜드 브리프가 PDF면 그대로 올리면 돼요. 작은 PDF는 바로, 큰 PDF는 Gemini에 자동 업로드한 뒤 읽어요.
  • 마음에 안 들면 빠른 다듬기로 한 번에 다듬는 게 새로 뽑는 것보다 빨라요.
  • API 키는 이 브라우저에만 저장돼요. 다른 기기에서는 한 번 더 넣어주세요.

결과는 참고용 초안이에요. 가격·효능·필수 표기는 올리기 전에 꼭 한 번 확인해 주세요.
