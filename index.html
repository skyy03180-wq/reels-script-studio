사용 팁+
  • 레퍼런스는 인스타 릴스를 화면 기록하거나 저장한 파일을 그대로 올리면 돼요. 3~60초면 충분해요.

  • 영상이 없어도 이미지·텍스트만으로 대본을 만들 수 있어요. 영상이 있으면 컷 템포와 말투까지 맞춰요.
  • 마음에 안 들면 빠른 다듬기로 한 번에 다듬는 게 새로 뽑는 것보다 빨라요.
  • API 키는 이 브라우저에만 저장돼요. 다른 기기에서는 한 번 더 넣어주세요.

결과는 참고용 초안이에요. 가격·효능·필수 표기는 올리기 전에 꼭 한 번 확인해 주세요.
