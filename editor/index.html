      5 내보내기 1080×1920 · 30fps

        MP4는 WebCodecs(H.264)로 프레임을 직접 뽑아 만들어요. 20초 릴스 기준 1~2분쯤 걸리고, 지원이 안 되는 브라우저에서는 실시간 녹화로 저장돼요. 자막은 캡컷·프리미어에 넣는 SRT, 나레이션·BGM만 따로 받는 WAV도 있어요.

        브라우저 지원

        내보내기가 안 되면 Chrome·Edge 최신 버전에서 열어 주세요. Safari는 WebCodecs 지원이 달라 실시간 녹화로 떨어질 수 있어요.

        사용법

        1. 클립 — 통영상에서 컷 따기

        1. ① 클립 위쪽 통영상에서 컷 따기에 5분짜리 원테이크 영상을 하나 올려요. (아래 클립 칸에 올린 영상도 소스로 바로 골라 쓸 수 있어요)
        2. 1x·2x·4x로 훑으면서 -5초 -0.5초 +0.5초 +5초로 위치를 맞춰요.
        3. 시작 지점에서 I(시작점), 끝 지점에서 O(끝점), 그리고 A 또는 Enter를 누르면 타임라인에 컷이 추가돼요. 같은 영상에서 몇 개든 계속 따서 이어 붙일 수 있어요.
        4. 빠르게 모을 땐 지금부터 2.5초 담기 / 3초 담기를 연타해요. 소스가 계속 재생되면서 다음 구간으로 넘어가요.
        5. 아래 클립 카드에서 순서(↑↓·드래그), 시작/끝 미세 조정, 배속(1.0~1.5x), 복제(⧉)·삭제(✕). 카드 썸네일을 누르면 그 구간이 소스 뷰어에 다시 열려요.

        2. 대본 → 자막

        1. 대본 스튜디오에서 만든 대본을 그대로 붙여넣고 자막으로 나누기.
        2. [0~3초 / ...] 타임코드는 자동으로 지워지고, 문장별로 전체 길이에 맞게 배분돼요.
        3. 첫 줄 후킹은 첫 줄 → 오프닝 타이틀로 바로 올릴 수 있어요.

        3. 오디오

        1. 나레이션은 캡컷 TTS에서 뽑은 mp3·m4a·wav를 올리면 파형을 분석해 숨 고르기·빈 구간을 자동으로 잘라내요. TTS를 넣은 mp4·mov 영상을 올려도 소리만 뽑아서 똑같이 처리해요.
        2. 무음 기준(dB)과 최소 무음 길이를 조절하고 다시 분석.
        3. BGM을 올리고 볼륨을 나레이션보다 낮게 잡아요.

        4. 내보내기

        1. MP4 내보내기 → 1080×1920 · 30fps H.264 파일이 다운로드돼요.
        2. 자막만 필요하면 SRT 자막을 받아 캡컷에 넣어요.
        3. 인스타 앱 업로드 시 자막이 UI에 가리지 않도록 아래쪽은 비워 뒀어요.

        단축키

        • Space 재생 / 일시정지
        • ← → 0.1초 이동 (Shift로 1초)

        참고

        영상과 오디오는 브라우저 안에서만 처리되고 어디에도 올라가지 않아요. 새로고침하면 편집 중인 내용은 사라져요.
